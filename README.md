# 🤖 AI Learning Assistant

A professional chatbot built with Python and Streamlit.

## Overview

AI Learning Assistant is an educational chatbot that answers questions about:

- Artificial Intelligence (AI)
- Python
- SQL
- Data Analytics
- Machine Learning
- Git
- GitHub

## Features

✅ Interactive Chat Interface  
✅ Chat History  
✅ Clear Chat Button  
✅ Sidebar Categories  
✅ FAQ Knowledge Base  
✅ Streamlit Web App
